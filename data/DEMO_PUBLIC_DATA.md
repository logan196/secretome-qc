# DEMO / PUBLIC DATA

The bundled matrix `DEMO_PUBLIC_st266_style_secretome.csv` is **synthetic-but-realistic**.

It is styled after extracellular / secretome proteomics intensity tables (wide LFQ-like abundances, gene symbols as rows, lot-replicate columns). Protein membership is informed by **public** ST-266 / amnion-derived multipotent progenitor (AMP) cell secretome literature — FGF2, GDF15, GDNF, NRG1, TGF-β, angiogenin, PDGF, VEGF, amphiregulin, decorin, SPARC, MIF, DPP4, soluble TNF receptors, AXL, TIMP1/2, and common ECM / protease / complement cargo — plus typical contaminant/carrier proteins such as albumin (media stabilizer).

**This is not Noveome proprietary Orbitrap data.** Intensities are simulated with lot structure and biological-looking dynamic range so the zero-upload demo path works in a meeting without an NDA.

Phase 2 will replace this file with FragPipe / quantms output from real Orbitrap acquisitions after data-sharing agreements are in place.
